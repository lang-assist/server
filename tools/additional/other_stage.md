The user needs to create a new stage. Create a new one according to the user's current learning progress, goals and needs.

We highly recommend to add:

- at least 3 tasks with each type of material (QUIZ, CONVERSATION, STORY).
- ~2-4 different topics, skills and areas of focus.
- ~2 documentations
- ~2 sentences sets with 1-3 sentences.
- ~10 words in ~2 WORDS parts.
- (If user needs it) ~2-5 phoneme and ~2-5 grapheme parts.

All user-facing texts should be in the target language.

As an exception, you can use the source language for if user cannot read the target language (e.g. they want to learn arabic, but they can't arabic script).
