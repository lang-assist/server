BrocaAgent prompt system uses XML-style tags to structure prompts. Each tag serves a specific purpose in guiding the AI's response generation. - : Defines the AI assistant's role and primary responsibility - : Contains task-specific instructions independent of context - : Holds context-dependent information provided by the server - : Contains the main request details from the server - : Defines the structure and rules for streaming JSON Lines output The JSONL tag defines how to structure streaming responses. Each line should be a complete, valid JSON object that can be processed independently. Each JSON line must include: - `type`: Identifies the type of content (e.g., "stage_part", "documentation", "feedback") - `action`: The operation to perform ("create", "update", "delete") - `payload`: The actual content following the defined schema {"type": "stage_part", "action": "create", "payload": {"id": "p1", "content": "Hello", "part_type": "text"}} {"type": "documentation", "action": "create", "payload": {"title": "Greeting", "content": "Basic greeting in English"}} - Each line must be a complete, valid JSON object - No line should depend on previous or future lines - Include all necessary context within each line - Use consistent type identifiers across related lines - Follow the defined schema for each type - Escape special characters properly - No trailing commas - No multi-line objects - UTF-8 encoding - No comments - Each line must end with a newline character - Use appropriate tags for structuring content - Follow tag hierarchy - Include all required attributes - Maintain consistent formatting - Mixing tag responsibilities - Skipping required tags - Using undefined tags - Nesting tags incorrectly
